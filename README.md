# VELORA Logo Redesign Project

VELORA is a fictional luxury fashion and beauty brand created for this logo redesign project. The objective of this project was to redesign the visual identity with a modern, elegant, and premium aesthetic while maintaining strong brand appeal and visual consistency.

The project includes custom logo variations, app icons, branding mockups, and digital UI presentations designed to showcase how the brand identity works across multiple real-world and digital applications.

## Skills Explored

* Logo Design
* Branding & Visual Identity
* Typography & Composition
* UI/UX Presentation
* Creative Direction
* Mockup Design
